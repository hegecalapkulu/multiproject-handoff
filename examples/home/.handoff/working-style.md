# Working style: general
Last updated: 2026-11-23

> Example of the general profile (~/.handoff/working-style.md). It is never inside a repo.
> Items arrive here only after showing up in two projects.

## Communication
- Plain language, no jargon unless the project profile allows it. (recipe-app, landing-page)

## Format
- Prefers a short table over long paragraphs when comparing options. (recipe-app, cli-tool)

## Approvals and safety
- Wants a list of affected files before any change touching more than 3 files. (recipe-app, landing-page)

## Gets in the way
- Long recaps of what was already said. (cli-tool, landing-page)
